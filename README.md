# Healthcare Data Analysis Dashboard

## Overview
This project is a healthcare data analytics dashboard built using Microsoft Power BI to explore patient demographics, hospital performance, and trends in medical conditions over time.

The goal of this project was to transform raw healthcare data into meaningful insights through data visualization and storytelling.

This is my second healthcare data analysis project, and it reflects significant improvement in:
- Dashboard design
- Data modeling
- DAX calculations
- Visual storytelling
- Analytical thinking

---

## Objectives
The dashboard was designed to answer key healthcare-related questions such as:

- Which hospitals recorded the highest patient volumes?
- Which medical conditions were most common?
- How do medical conditions vary across age groups?
- What is the gender distribution of patients?
- How have medical conditions changed over time?

## Key Insights
Some insights identified from the analysis include:

- Hypertension remained one of the most consistently reported medical conditions across the years analyzed.
- Patients aged 51–65 showed higher frequencies across multiple medical conditions.
- The patient population was relatively balanced by gender.
- Chronic conditions such as hypertension and arthritis accounted for a significant proportion of patient admissions.
